# strong-sales-report-generator-a7k2fx
STRONG Sales Report Generator

Use this one URL. It never changes: https://salesvp.github.io/strong-sales-report-generator-a7k2fx/

It always opens the newest generator file in this repo.

To publish a new version: upload it as `STRONG_Generator_Mk<N>_v<N>.html` (for example `STRONG_Generator_Mk2_v5.html`). Do not rename it and do not edit `index.html`. The highest Mk/v number is loaded automatically. Older versions stay in the repo and can still be opened by their own file names.
